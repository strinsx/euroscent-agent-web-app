# EuroScent Agency Web App

A full-stack eCommerce web application built using the **MERN Stack** with **Cloudinary** integration for image uploads and management.

This project follows the **MVC Architecture** and implements complete **CRUD functionality** for products, users, and orders. The application was built to improve my understanding of backend structure, scalable project organization, authentication systems, and deployment workflows.

# 🧠 Concepts Used

## MVC Architecture
This project uses the **Model-View-Controller** design pattern to separate application logic into organized sections:

- **Models** → Database Schemas
- **Controllers** → Business Logic
- **Routes** → API Endpoints

This was my first time fully implementing the MVC structure in a real-world MERN application.
